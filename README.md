# Video Progress Tracker - Frontend

This is the **Frontend application** for the Video Progress Tracker project.  
It allows users to watch videos and automatically track/save their watch progress.

## 🛠️ Tech Stack

- React.js
- Axios (for API calls)
- SweetAlert2 (for beautiful alerts)
- CSS (custom styling)

## 🚀 Features

- Track watched intervals of the video
- Calculate and display video progress percentage
- Automatically save progress to backend
- Resume video progress on reload
